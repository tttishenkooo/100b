# Школьные задания — Vercel + Supabase

Небольшой «Moodle»: учитель публикует задания, ученики сдают ответы (текст, фото тетради, файлы), учитель ставит оценки или возвращает на доработку, всё сводится в журнал с выгрузкой в Excel.

**Почему должно работать без VPN.** Браузер ученика общается только с вашим сайтом. К Supabase обращается сервер Vercel из Франкфурта, поэтому блокировки Supabase в России ученикам не мешают. Отдельный вопрос — доступность самого Vercel (см. шаг 5).

## Что умеет

- **Учитель:** классы; добавление учеников списком (логины и пароли создаются автоматически, их можно распечатать); задания с файлами, сроком и максимальным баллом; запрет сдачи после срока; проверка с быстрыми кнопками баллов и комментарием; «вернуть на доработку»; после проверки сразу открывается следующая работа; журнал с цветными оценками и выгрузкой в Excel; выдача нового пароля, перевод в другой класс, удаление ученика.
- **Ученик:** список «Нужно сделать / На проверке / Проверено»; ответ текстом и файлами; фото с телефона автоматически сжимаются; ответ можно исправить, пока учитель его не проверил.
- **Защита:** пароли хранятся в виде хэшей; после 15 неудачных попыток вход блокируется на 15 минут; при смене или сбросе пароля старые входы перестают работать; чужие файлы и ответы недоступны; таблицы закрыты от публичного API Supabase.

## Установка (примерно 20 минут)

### 1. Supabase — база данных

1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и нажмите **New project**.
2. **Region:** выберите **Central EU (Frankfurt)** — рядом с сервером сайта, так страницы открываются быстрее. Пароль базы придумайте любой и сохраните.
3. Когда проект создастся, откройте слева **SQL Editor → New query**, вставьте всё содержимое файла `supabase.sql` и нажмите **Run**. Должно появиться «Success».
4. Откройте **Project Settings → API Keys** и сохраните два значения:
   - **Project URL** (вида `https://abcd1234.supabase.co`; также есть в **Project Settings → Data API**);
   - **Secret key** (`sb_secret_…`). Если в проекте есть только старые ключи, возьмите **service_role** на вкладке «Legacy API keys».

   ⚠️ Секретный ключ даёт полный доступ к базе: никому его не показывайте и не вставляйте в код.

### 2. GitHub — где хранится код

1. Зарегистрируйтесь на [github.com](https://github.com) и нажмите **New repository**: имя, например, `shkola`, тип **Private**.
2. На странице репозитория нажмите **uploading an existing file** и перетащите **все файлы и папки** этого проекта (`api`, `lib`, `public`, `vercel.json`, `package.json` и остальные). Нажмите **Commit changes**.

### 3. Vercel — публикация сайта

1. Зарегистрируйтесь на [vercel.com](https://vercel.com) через GitHub и нажмите **Add New → Project**, затем выберите репозиторий `shkola` → **Import**.
2. **Framework Preset:** Other. Build-настройки не трогайте.
3. Раскройте **Environment Variables** и добавьте:

| Имя | Значение |
|---|---|
| `SUPABASE_URL` | Project URL из шага 1 |
| `SUPABASE_SECRET_KEY` | секретный ключ из шага 1 |
| `SESSION_SECRET` | любая длинная случайная строка, 30+ символов |
| `SETUP_KEY` | придумайте слово: оно понадобится один раз при создании учителя |

Необязательные переменные: `APP_NAME` (название в шапке, по умолчанию «Школьные задания») и `APP_TIMEZONE` (по умолчанию `Europe/Moscow`; например, `Asia/Yekaterinburg`).

4. Нажмите **Deploy**. Через минуту появится адрес вида `shkola-xxx.vercel.app`.

### 4. Первый вход

Откройте сайт, введите `SETUP_KEY`, своё имя, логин и пароль. Затем откройте **Ученики**: создайте класс, вставьте список учеников («Фамилия Имя», по одному на строку) и распечатайте логины и пароли. Пароли показываются **один раз**; если пароль потеряется, нажмите «⋯ → Выдать новый пароль».

### 5. Доступ без VPN — свой домен (очень рекомендуется)

Доступ к Vercel из России зависит от IP-адреса. По сообщениям пользователей (сентябрь 2026), адрес **76.76.21.21** открывается, а некоторые другие адреса Vercel, на которые ведут `*.vercel.app`, у части провайдеров не грузятся. Поэтому:

1. Купите домен, например `.ru`, у любого регистратора (около 200–900 ₽ в год).
2. В Vercel откройте проект → **Settings → Domains → Add** и введите домен.
3. У регистратора, в настройках DNS домена, создайте **A-запись**: `@` → `76.76.21.21`. Для `www` можно добавить CNAME → `cname.vercel-dns.com`. Сервера имён (NS) лучше оставить у регистратора.
4. Подождите от 15 минут до нескольких часов и **проверьте сайт с телефона через мобильный интернет без VPN**, лучше у разных операторов.

Если Vercel всё равно где-то не открывается, тот же код можно запустить на любом российском хостинге с Node.js 20+: `node standalone.js`, а переменные из таблицы выше указать в файле `.env`. База и файлы останутся в Supabase.

## Ограничения и полезное

- **Файлы:** до 10 штук к ответу, каждый до 4 МБ (это ограничение Vercel). Большие фото сжимаются в браузере автоматически, так что снимки тетради проходят без проблем.
- **Бесплатный Supabase засыпает**, если к проекту 7 дней никто не обращается (например, на каникулах). Тогда сайт выдаст ошибку: зайдите в панель Supabase и нажмите **Restore project**. Данные при этом не теряются.
- **Резервная копия:** Supabase → **Database → Backups**. Журнал можно в любой момент скачать кнопкой «Скачать для Excel».
- **Поменять пароль учителя:** нажмите на своё имя в правом верхнем углу.
- **Обновить сайт:** замените файлы в GitHub, и Vercel переопубликует сайт сам.

## Устройство (для тех, кто будет дорабатывать)

- `api/index.js` — единственная серверная функция Vercel; `vercel.json` направляет в неё все адреса.
- `lib/app.js` — маршруты, вход и сессии (подписанная cookie на 30 дней); `lib/teacher.js` и `lib/student.js` — страницы; `lib/view.js` — оформление; `lib/files.js` — файлы.
- `lib/supabase.js` — доступ к базе через функцию `app_sql` (SQL с параметрами) и к Storage по REST. npm-зависимостей нет.
- `dev/fake-supabase.js` — эмулятор Supabase поверх локального PostgreSQL для тестов.
